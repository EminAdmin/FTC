# 🐍 FunTimeCobra — Voxel Anarchy Engine & Server

Экспериментальный 3D-воксельный движок на C# (Raylib-cs), разрабатываемый как полноценный open-source аналог Anarchy-серверов (по типу FunTime).

> ⚠️ **Проекту нужны мейнтейнеры и разработчики!** 
> Движок находится на стадии активной разработки базовых систем. Мы ищем C# разработчиков, чтобы превратить этот проект в готовый сервер с полной экосистемой.

---

## 🎯 Глобальная цель проекта
Создать полностью рабочий, оптимизированный воксельный сервер-клиент с готовыми механиками Анархии: от физики движения до привилегий и модерации.

---

## 🗺 Roadmap / Что нужно доделать (Задачи для контрибьюторов)

### 1. 🛠 Движок и Физика (Приоритет: Высокий)
- [ ] **Исправление AABB-коллизий:** Переработка физики игрока, чтобы исключить застревание в блоках и дискретное движение по сетке.
- [ ] **Механика `/rtp`:** Безопасный телепорт на +15 блоков выше земли с эффектом `Slow_Falling` (замедленное падение).
- [ ] **Генерация мира & Блоки:** Расширение реестра блоков (все блоки/предметы из Minecraft 1.16+) и поддержка прозрачности/полублоков.

### 2. 👑 Система Привилегий и Доната
- [ ] **Система групп и прав (Permissions):** Иерархия ролей (Игрок, VIP, Premium, COBRA и т.д.).
- [ ] **Донат-киты и предметам:** Поддержка кастомных талисманов, сфер, китов и их лора.
- [ ] **Экономика:** Баланс игроков, покупка/продажа предметов, интеграция аукциона.

### 3. 🛡 Система Модерации и Администрирования
- [ ] **Команды модерации:** `/ban`, `/mute`, `/kick`, `/warn`, `/freeze` (проверка на читы).
- [ ] **Логирование:** Логи чата, команд, передач вещей и разрушения блоков.
- [ ] **Античит база:** Базовые проверки на Fly, Speed, NoClip и FastBreak.

### 4. 🌐 Сетевой код и Интерфейс
- [ ] **UI / HUD:** Полноценный скорборд (Scoreboard), кастомный хотбар, отображение активных талисманов и зон безопасности.
- [ ] **Сетевая оптимизация:** Синхронизация чанков и игроков по локальной сети и внешним IP.
